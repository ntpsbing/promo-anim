想要真人配音更生動？

  1. 請老師或學生依旁白稿配音，「小楠」的台詞可以請小朋友來念，效果最好。
  2. 關掉上方的「語音旁白」，保留「字幕」「配樂」「音效」。
  3. 按播放，照著畫面下方的字幕念，時間會剛好對上。
  4. 用「輸出影片」的方法一錄影，麥克風的聲音會一起錄進去。

方法一：Windows 螢幕錄影 最推薦

畫面、配樂、音效、語音旁白全部錄進去。

  1. 按舞台右下角的全螢幕按鈕。
  2. 按 Win + Alt + R 開始錄影（Xbox Game Bar）。
  3. 按播放，播完再按一次 Win + Alt + R 停止。
  4. 影片會存在「影片 › 擷取」資料夾，是 MP4 檔，可直接傳 LINE。

若按了沒反應：開啟 PowerPoint →「插入」→「螢幕錄製」也可以錄。

方法二：直接下載影片檔 網路版推薦

含畫面、字幕、配樂、音效和「自己的配音」。電腦語音因瀏覽器限制錄不進去，需要旁白請在「分鏡編輯」每一幕按「● 錄音」或上傳音檔。錄製會即時播放一遍，請停留在這個分頁。

播放小提醒

  • 朝會或班級播放：開全螢幕直接播最清楚，字幕在大螢幕也看得到。
  • 沒有聲音？先按一下播放鍵，瀏覽器要等你點擊後才允許出聲。
