# 楠小宣導動畫工作室

高雄市楠梓國小的宣導動畫小工具：選範本、改文字，就能做出約 1 分鐘、含字幕、配樂、音效與學校吉祥物的宣導動畫，並直接下載成影片。

**線上使用：** https://ntpsbing.github.io/promo-anim/

**圖解教學：** https://ntpsbing.github.io/promo-anim/guide/

## 老師怎麼用
1. 用電腦的 Edge 或 Chrome 打開上面的網址。
2. 「範本」選一個主題，舞台下方選觀眾風格。
3. 「分鏡編輯」修改每一幕的文字；按「● 錄音」可以用自己的聲音配音。
4. 「輸出影片」按「開始錄製」，播完就能下載 MP4，直接傳 LINE。

每位老師的作品只存在自己的電腦，不會互相影響。要分享給其他老師，可用「匯出作品／匯入作品」。
